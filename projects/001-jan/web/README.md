# Jan 研究页面

一页整理 Jan 的定位、基础链路、能力模块、研究价值与我们的后续方向。首屏明确说明：**Jan 是一个类 ChatGPT 的开源桌面 App。**

页面是静态研究展示，不调用模型，不提供聊天功能，不采集用户输入。原生折叠面板用于阅读十八个模块；所有结论链接回固定提交或研究文档。

## 页面内容

1. 产品定位：应用、模型和推理引擎分别负责什么。
2. 基础链路：输入、上下文、模型适配、推理和反馈。
3. 扩展能力：资料与记忆、工具与子 Agent、下载升级、文件和设置。
4. 使用价值、架构参考价值与适用边界。
5. 我们的方向：实现软件，也公开呈现模块、源码、运行过程和设计取舍。
6. 研究来源与尚未验证的事项。

## 独立运行

依赖：Python 3.10+，仅使用标准库。无需 Node 依赖、API Key 或后端服务。

从本目录运行：

```powershell
python build.py
python -m http.server 8767 --bind 127.0.0.1 --directory dist
```

打开本地地址 [Jan 研究页](http://127.0.0.1:8767/)。该地址仅在本地服务运行时有效，不是已部署的互联网地址。

## 文件组织

| 文件 | 用途 |
| :--- | :--- |
| `index.html` | 中文页面正文、模块内容和来源链接 |
| `styles.css` | 桌面与移动布局、打印样式、键盘焦点 |
| `build.py` | 汇总页面、上级 assets 图和 notes 文档到 dist |
| `.openai/hosting.json` | 静态发布目录声明；未注册站点，不含项目 ID |
| `dist/` | 生成产物，沿用根忽略规则，不提交 |

架构图从项目的 assets 目录获取，正文文档从 notes 获取，避免手工维护多份图片与文档。页面内容修改后重新运行 build.py。网页使用相对资源链接，可按[部署约定](../../../docs/DEPLOYMENT.md)部署到子路径。
