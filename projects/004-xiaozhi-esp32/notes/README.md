## 不直接沿用的简化表述

1. “模拟 AI”只用于拟人交互外观；联网后端可以是真实 AI 推理，不能写成假聊天程序。
2. “给任意板子烧录即可”不成立：硬件接口、电源、驱动、存储和固件配置需匹配。
3. “N16R8 就是官方照片型号”不成立：不同开发板有不同订货和存储组合，必须核对实际型号。
4. “相同 GPIO 配置适用于所有版本”不成立：已发现官方板 v1.1 RGB 灯 38 与面包板配置 48 的差异。
5. “图中所有模块都必须购买”不成立：面包板照片含未完全确认的扩展板，Wi-Fi 原型不据此增加采购。
6. “主板是唯一难点”不成立：供电、声学、任务调度、状态管理、网络和后端都会影响效果。
7. “自制 PCB 就把开发板拆焊搬过去”不成立：应重新设计、采购元件、制造贴装和验证。
8. “网页演示通过就等于固件可用”不成立：页面只作教学，不连接硬件或后端。
