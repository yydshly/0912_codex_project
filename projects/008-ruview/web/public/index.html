HOW IT WORKS

无线信号如何成为感知结果？

本实验真正执行下方 ② 与 ③。① 的信号由我们生成，④ 需要额外模型与现场验证。

01

获取 CSI

人体运动改变反射路径，接收器得到各子载波的幅度和相位。本演示用已知频率合成幅度变化，未模拟完整无线传播。

真实部署：支持 CSI 的硬件与固件
02

消除静态背景

RuView 的 CsiVitalPreprocessor 跟踪幅度基线，用指数移动平均去除静态分量，得到随时间变化的残差。

本演示：原版 Rust 模块实际执行
03

寻找周期

呼吸算法使用带通滤波和过零分析；心率算法结合相位一致性加权、带通滤波与自相关寻找主周期。

本演示：与输入真值逐项对照
04

推断更复杂状态

存在、动作与姿态涉及其他模块、规则或训练模型。姿态估计还需要匹配的硬件输入、模型权重与房间适配。

本演示：展示证据，不伪造推理输出

试一试这三个对照

安静呼吸 → 较快节律：观察估计值是否跟随输入变化。

安静呼吸 → 运动干扰：即使输入真值不变，干扰也可能让算法锁定到错误周期。

56 子载波 → 单子载波：观察输入信息减少后，原版算法怎样调整质量分数与状态。

实验中的 45 秒是输入信号时长；“计算用时”是本机加速处理这段信号的耗时，两者含义不同。
